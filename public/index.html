# 한진 2026년 신입사원 프리보딩 홈페이지 ## 📌 프로젝트 소개 한진 2026년도 신입사원을 위한 프리보딩 웹사이트입니다. 입사 전 신입사원들이 서로 소통하고 친해질 수 있는 온라인 공간을 제공합니다. ### 주요 기능 - **공지사항**: 관리자가 작성하는 중요 안내사항 - **방명록**: 간단한 인사말과 함께 사진 업로드 (최대 5장) - **자기소개 게시판**: 제목과 내용으로 자신을 소개하고 사진 첨부 가능 (최대 5장) - **회원 시스템**: 회원가입, 로그인, 권한 관리 - **이미지 업로드**: 방명록과 자기소개에 여러 장의 사진 업로드 및 갤러리 뷰 ### 🎨 디자인 특징 - **한진 공식 브랜드 컬러** 적용 - Hanjin Dark Blue (#05246D) - Hanjin Cobalt Blue (#1E5EC6) - Hanjin Cyan Blue (#00C4FF) - 반응형 디자인 (모바일/태블릿/PC) - 한진 로고 통합 - 현대적이고 직관적인 UI/UX --- ## 🚀 설치 및 실행 방법 ### 1. 사전 준비 먼저 **Node.js**를 설치해야 합니다. 1. [Node.js 공식 홈페이지](https://nodejs.org/ko) 접속 2. **LTS 버전** (왼쪽 버튼) 다운로드 3. 설치 파일 실행 후 안내에 따라 설치 4. 설치 확인: ```bash node -v npm -v ``` ### 2. 프로젝트 다운로드 프로젝트 파일을 다운로드하고 원하는 폴더에 압축을 해제합니다. 예: `C:\hanjin-preboarding-2026` ### 3. 명령 프롬프트에서 프로젝트 폴더로 이동 1. Windows 검색에서 `cmd` 입력 → 명령 프롬프트 실행 2. 프로젝트 폴더로 이동: ```bash cd C:\hanjin-preboarding-2026 ``` (경로는 실제 저장 위치로 변경) ### 4. 의존성 패키지 설치 ```bash npm install ``` - 1~3분 정도 소요됩니다 - 프로젝트에 필요한 모든 라이브러리를 자동으로 설치합니다 ### 5. 데이터베이스 초기화 ```bash npm run init-db ``` - **처음 한 번만 실행**하면 됩니다 - 데이터베이스 파일(`hanjin_preboarding.db`)과 초기 데이터를 생성합니다 - 기본 관리자 계정이 자동으로 생성됩니다 ### 6. 서버 실행 ```bash npm start ``` - 서버가 정상적으로 실행되면 다음 메시지가 표시됩니다: ``` ============================================== 한진 2026 신입사원 프리보딩 홈페이지 서버가 http://localhost:3000 에서 실행 중입니다 ============================================== ``` ### 7. 웹사이트 접속 웹브라우저를 열고 주소창에 입력: ``` http://localhost:3000 ``` --- ## 👤 기본 계정 정보 ### 관리자 계정 - **아이디**: `admin` - **비밀번호**: `admin123` ⚠️ **보안을 위해 첫 로그인 후 비밀번호를 변경하세요!** --- ## 🌐 다른 사람도 접속하게 하기 ### 내 컴퓨터의 IP 주소 확인 1. **새 명령 프롬프트** 창 열기 (서버 실행 중인 창 말고) 2. 다음 명령어 입력: ```bash ipconfig ``` 3. **IPv4 주소** 찾기 (예: `192.168.0.15`) ### 신입사원들에게 알려주기 "브라우저에서 `http://192.168.0.15:3000` 접속하세요!" (여기서 `192.168.0.15`는 위에서 찾은 IP 주소로 변경) ### ⚠️ 주의사항 - **서버를 실행한 컴퓨터는 계속 켜져 있어야** 합니다 - **같은 네트워크(WiFi/LAN)**에 연결되어 있어야 접속 가능합니다 - 방화벽 설정이 차단하는 경우 허용 설정이 필요할 수 있습니다 --- ## 🔄 서버 관리 ### 서버 종료하기 명령 프롬프트 창에서 `Ctrl + C` 누르기 ### 다음에 다시 시작하기 ```bash cd C:\hanjin-preboarding-2026 npm start ``` **참고**: `npm install`과 `npm run init-db`는 처음 한 번만 하면 됩니다! ### 데이터베이스 초기화 (데이터 모두 삭제) ```bash npm run init-db ``` --- ## 📸 이미지 업로드 기능 ### 지원 형식 - **파일 타입**: JPG, PNG, GIF, WEBP - **파일 크기**: 각 이미지 최대 5MB - **업로드 개수**: 게시글당 최대 5장 ### 사용 방법 1. **방명록/자기소개 작성** 버튼 클릭 2. "사진 첨부" 영역 클릭 또는 파일 드래그 3. 업로드할 이미지 선택 (여러 장 가능) 4. **미리보기**에서 이미지 확인 5. 삭제하고 싶은 이미지는 ❌ 버튼 클릭 6. "작성 완료" 버튼으로 게시 ### 이미지 보기 - **썸네일 클릭**: 큰 화면으로 확대 보기 - **라이트박스**: 이미지 클릭 시 전체 화면으로 감상 - **갤러리 뷰**: 자기소개 상세보기에서 모든 이미지 그리드 표시 --- ## 🛠️ 기술 스택 ### 백엔드 - **Node.js**: JavaScript 런타임 - **Express**: 웹 프레임워크 - Node.js가 제대로 설치되지 않았습니다 - Node.js 재설치 후 명령 프롬프트를 **새로 열기** ### "포트 3000이 이미 사용 중입니다" 오류 - 다른 프로그램이 3000번 포트를 사용 중입니다 - 컴퓨터를 재시작하거나 포트 번호를 변경하세요 - `server.js`에서 `PORT = 3000`을 다른 번호로 변경 ### 다른 사람이 접속이 안 됩니다 1. 서버가 실행 중인지 확인 2. 같은 WiFi/네트워크에 연결되어 있는지 확인 3. 방화벽 설정 확인 (Windows Defender 방화벽) 4. IP 주소가 올바른지 재확인 ### 이미지 업로드가 안 됩니다 1. 파일 크기가 5MB를 초과하지 않는지 확인 2. 이미지 파일 형식(JPG, PNG, GIF)인지 확인 3. 최대 5장을 초과하지 않았는지 확인 4. `uploads` 폴더의 쓰기 권한 확인 ### 데이터베이스가 손상되었습니다 ```bash # 데이터베이스 파일 삭제 rm hanjin_preboarding.db (Mac/Linux) del hanjin_preboarding.db (Windows) # 데이터베이스 재초기화 npm run init-db ``` --- ## 📱 브라우저 지원 - ✅ Chrome (권장) - ✅ Microsoft Edge - ✅ Firefox - ✅ Safari - ⚠️ Internet Explorer: 지원하지 않음 --- ## 🎯 사용자 가이드 ### 일반 사용자 (신입사원) 1. **회원가입**: 우측 상단 "회원가입" 버튼 2. **로그인**: 아이디와 비밀번호 입력 3. **공지사항 확인**: 중요한 안내사항 읽기 4. **방명록 작성**: 간단한 인사와 사진 남기기 5. **자기소개 작성**: 자신을 소개하고 동기들 알아가기 ### 관리자 1. **관리자 로그인**: `admin` / `admin123` 2. **공지사항 작성**: 중요 안내사항 게시 3. **게시물 관리**: 부적절한 글/사진 삭제 4. **사용자 관리**: 필요 시 데이터베이스에서 직접 관리 --- ## 📝 추가 개발 아이디어 향후 추가할 수 있는 기능들: - [ ] 댓글 기능 - [ ] 좋아요/공감 기능 - [ ] 프로필 사진 설정 - [ ] 게시물 검색 기능 - [ ] 페이지네이션 (게시물 페이징) - [ ] 이메일 알림 기능 - [ ] 다크 모드 - [ ] 실시간 채팅 - [ ] 설문조사 기능 --- ## 📞 문의 및 지원 프로젝트 관련 문의사항이나 버그 리포트는 관리자에게 연락주세요. --- ## 📄 라이선스 이 프로젝트는 한진 내부 사용 목적으로 제작되었습니다. --- ## 🙏 감사합니다 한진 2026년 신입사원 여러분의 입사를 진심으로 환영합니다! 🎉 이 프리보딩 홈페이지를 통해 서로 친해지고, 설레는 마음으로 첫 출근을 준비하시길 바랍니다. **함께 성장하는 한진이 되겠습니다!** 💙
